# Behavioral / Experience Questions

The prep checklist is at the [bottom of this file](#prep-checklist).

## 1. Tell me about a complex problem you solved

**a) Migration from Gatsby to Next.js**

Goal: reduce the build time and improve page speed by implementing SSG (Static Site Generation), and keep builds automatically up to date using ISR (Incremental Static Regeneration).

**b) Login issue when connecting the app and the web**

**c) Batch processing of a large user list**

Looped over the user list and updated user details in batches to stay within memory limits.
