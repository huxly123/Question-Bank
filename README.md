# Question Bank

Personal interview preparation notes — theory, output questions, code snippets, and DSA practice, organized by topic. Every question's answer is collapsed behind a **details** toggle, so you can quiz yourself: read the question, answer it in your head, then expand to check.

## How this repo works

1. **Pick a topic** from [TODO.md](TODO.md) — the single checklist of everything still to study.
2. **Learn it and write it up** in the matching note file (or a new file), following [template.md](template.md).
3. **Check it off in TODO.md** and turn the item into a link to the section you wrote — so TODO stays the "what's next" view and the notes stay the "what I know" view.
4. **Revise** by opening a note file on GitHub and answering the questions before expanding them.

**Adding a new topic area:** create a folder with a `theory.md` (see [template.md](template.md)), add its topics to TODO.md, and link the file below.
